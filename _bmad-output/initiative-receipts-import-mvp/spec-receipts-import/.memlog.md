- (capability) CAP-1 intake: allowlisted family member (Telegram user ID) submits a receipt in a private chat as a photo or as a document (image or PDF)
- (capability) CAP-2 extraction: one extraction per receipt yields chain, branch, purchase date and time, line items, discounts and settlement, for clean digital and crumpled paper receipts of supported chains
- (capability) CAP-3 line pricing: each line keeps printed values plus computed regular price before discount and effective price actually paid
- (capability) CAP-4 settlement: receipt records how it was settled (card, cash, bonus points, receipt-level coupons, deposit refunds); amounts may be negative when cashier pays out
- (capability) CAP-5 consistency check: items and settlement must agree; a failing receipt is not written and takes the failure path
- (capability) CAP-6 deduplication: the same purchase sent twice is stored once; sender sees a dedicated duplicate reaction and the configured duplicate message
- (capability) CAP-7 atomic storage: receipt, items and settlement written to PostgreSQL in one atomic unit or not at all
- (capability) CAP-8 outcome feedback: sender and admin learn the outcome of every receipt per the outcome matrix (success, duplicate, unknown chain, failure with reason and file copy to admin)
- (capability) CAP-9 durable waiting: while extraction service is unavailable receipt waits with no deadline, survives restart, sender sees in-progress reaction; responds-without-valid-result gets bounded attempts then failure path
- (capability) CAP-10 operational alerts: errors the service catches in its own work reach the admin in Telegram, not only logs
- (capability) CAP-11 Resolver handoff: the downstream Resolver learns a receipt was stored via a contract this project owns, in docs/contracts/, semver-versioned from day one and recorded in docs/api-versions.md; MVP not done without it
- (constraint) Extraction via Gemini Flash paid tier only (keeps receipt data out of training); images with items, branch address and masked loyalty-card number leave the host; cost cents per month

- (constraint) No manual-correction path: recovery from any failure is resending a better photo or file
