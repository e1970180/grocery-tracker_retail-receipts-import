## Flow
- Pass 1 asks only chain, store_name, purchase_date, purchase_time (domain/chains/pass1.py:11-19 Pass1Response; prompt pass1.py:56-60 build_pass1_prompt). It supplies no stored field: date/time only feed `precheck` for resend lookup (app/pipeline.py:124-137 precheck); its store_name is used only for the Unsupported outcome (pipeline.py:195-196 _detect_chain).
- Load-bearing: pass 2 is `ports.generate(data, mime, plugin.pass2_prompt, plugin.pass2_schema)` (pipeline.py:213 _extract); the response goes to `plugin.normalize` (pipeline.py:216); UnreadableReceipt becomes `Invalid(NO_VALID_RESULT, ...)` (pipeline.py:217-218). ## Per stored field (schema spar/schema.py SparPass2; normalizer spar/normalize.py normalize :28-48)

- chain_id: no response field; constant "spar" from the plug-in key, never from model text (spar/__init__.py:16, 33-34). Model validator rejects non-slugs (domain/receipt.py:160-166) -> UnreadableReceipt (normalize.py:47-48). Fixtures: "spar" in all four expected.json (line 3).
- store_name: SparPass2.store_name required str, "Store line under the company OIB line" (schema.py:31). Prompt: line under the MB and OIB line, never "SPAR HRVATSKA D.O.O." (prompt.py:9-10). Normalizer `.strip()` (normalize.py:38). Missing key fails the schema (normalize.py:29-33); empty after strip fails min_length=1 (receipt.py:149) -> UnreadableReceipt. Fixtures (expected.json:4, pass2.json:3): 0100 "SPAR SUPERMARKET ZG-BAKIĆEVA"; 1402, 2600, 7088 "INTERSPAR ARENA ZAGREB".
- store_address: `str | None` default None, "Line under the store line" (schema.py:32); prompt "the line printed under the store line" (prompt.py:11); `_stripped` makes blank into None (normalize.py:41, 66-69); missing gives None with no error. Fixtures (expected.json:7, pass2.json:4): 0100 "Vojina Bakića 1, 10000 Zagreb"; 1402, 2600, 7088 "V.Vukova 6, 10000 Zagreb".
- receipt_number: `str | None`, value after 'Broj računa:' as printed (schema.py:33-35; prompt.py:14); `_stripped` (normalize.py:40); missing gives None. Fixtures (expected.json:6, pass2.json:5): 0100 "56786/87085/102"; 1402 "31104/8714/153"; 2600 "3169/8714/103"; 7088 "45984/8714/154".
- branch_number: no response field, no prompt instruction; derived from receipt_number, the middle segment of sequence/branch/till (normalize.py:39, 72-80). Missing or blank receipt_number gives None. A receipt_number that is not exactly three "/"-separated all-digit segments raises UnreadableReceipt (normalize.py:78-79), so an optional field can fail the whole receipt. Fixtures (expected.json:5; pass2.json has no branch key): 0100 "87085"; 1402, 2600, 7088 "8714".
- loyalty_card_number: no source; not in SparPass2, prompt or normalizer; model default None (receipt.py:153), so Spar always stores NULL; writer reads receipt.loyalty_card_number (adapters/postgres/receipts.py:187). No match for "loyalty" in any of the twelve Spar fixture files. schema.py:1-4 says the schema deliberately has no field for the card slip so card numbers and terminal ids never leave the PDF; prompt.py:25-26 tells the model to leave out the card slip.
- currency: no source; `Literal["EUR"]` default (receipt.py:154); prompt mentions EUR only as the header row used to find the lines (prompt.py:15, 18); absent from the four expected.json.
- purchased_at: purchase_date DD.MM.YYYY and purchase_time HH:MM, both required (schema.py:36-37); prompt: only from "Vaša kupnja dana DD.MM.YYYY. u HH:MM sati", never the card slip's DATUM/VRIJEME (prompt.py:12-13); `_purchase_time` fullmatch DATE and TIME patterns, trailing "." on the date allowed (normalize.py:23-24, 83-93); converted by zagreb_to_utc at minute precision (receipt.py:248-257). Pattern mismatch or impossible date raises UnreadableReceipt (normalize.py:86-87, 92-93). Fixtures: 0100 22.03.2026 12:47 -> 2026-03-22T11:47:00Z; 1402 18.05.2026. 10:15 -> 2026-05-18T08:15:00Z; 2600 16.05.2026 14:31 -> 2026-05-16T12:31:00Z; 7088 10.06.2026. 15:07 -> 2026-06-10T13:07:00Z.
- total: required (schema.py:38); prompt "the UKUPNO amount" (prompt.py:22); `_money` accepts only `-?\d+,\d{2}` (normalize.py:22, 96-100, 43); other shapes raise UnreadableReceipt. Fixtures: 27,18; 3,79; 54,25; 6,02.
